# NEVRA R/01

A fictional performance-car launch site built with Vite, vanilla JavaScript, GSAP, Lenis, and a Seedance 2.5 frame sequence.

## Live concept

[nevra-r01-launch.vercel.app](https://nevra-r01-launch.vercel.app)

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run check
npm run build
```

To rebuild the delivery pack from 451 numbered WebP frames: `npm run pack:frames -- /path/to/frames`.

The deployment is intentionally marked `noindex`. The vehicle, specifications, and footage are fictional concept material.
